# ALBAZ Yallop Crescent Visibility Maps

خرائط عالمية لإمكانية رؤية الهلال وفق معيار **Yallop q-test**، إصدار ويب مستقل **v9.6.3**.

## المستودع المقترح

`ALBAZ-YALLOP-CRESCENT-VISIBILITY-MAPS`

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا بالاسم المقترح.
2. ارفع **محتويات هذه الحزمة** إلى جذر المستودع.
3. افتح `Settings → Pages`.
4. اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/(root)` ثم `Save`.

سيصبح الرابط عادةً:

`https://USERNAME.github.io/ALBAZ-YALLOP-CRESCENT-VISIBILITY-MAPS/`

## الملفات

- `index.html`: التطبيق الرئيسي.
- `guide.html`: الدليل العلمي والتشغيلي.
- `manifest.webmanifest`: بيانات تطبيق الويب.
- `icon.svg`: أيقونة المشروع.
- `.nojekyll`: نشر مباشر للملفات الثابتة.
- `404.html`: صفحة رجوع إلى التطبيق.
- `NOTICE.md`: الإسناد والتنبيه العلمي.
- `CITATION.cff`: بيانات الاستشهاد بالمشروع.
- `QA_REPORT.md`: تقرير الاختبارات.

## الأساس العلمي

يطبق البرنامج معادلة يالوب q-test وفئات A–F. راجع `guide.html` للتفاصيل والمعادلات والحدود العددية.

## تنبيه

النتائج تنبؤية واحتمالية، وتتأثر الرؤية الفعلية بالطقس والأفق وخبرة الراصد ووسيلة الرصد. البرنامج أداة بحثية ولا يصدر إعلانًا رسميًا أو حكمًا شرعيًا.
